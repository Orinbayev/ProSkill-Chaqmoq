Assalomu alaykum!

Biz "Chaqmoq" (O'quv markazlarini boshqarish SaaS platformasi) loyihasi uchun Click orqali to'lovlarni qabul qilishni yo'lga qo'ymoqchimiz va buning uchun Click API (Shop API Webhook) bilan integratsiya qilyapmiz.

Lekin merchant.click.uz (Merchant kabinet) ga kirish uchun login va parol (yoki shartnoma bo'yicha ruxsat) bizda mavjud emas.

Iltimos, kompaniyamiz nomidan ruxsat olish (ro'yxatdan o'tish) bosqichlari haqida va loyihamizga kerak bo'lgan quyidagi API ma'lumotlarini qanday qilib qo'lga kiritish bo'yicha yo'l-yo'riq ko'rsatsangiz:
- Merchant ID
- Service ID
- Secret Key (MD5 kalit)

Biz hujjatlar bilan qanday shartnoma qilishimiz kerak? Javobingizni kutib qolamiz, oldindan rahmat!
